变量是给内存里的一块地方起名字。类型决定这块地方多大、里面的比特怎么解释。

这两个概念必须一起理解，否则会出现「我明明存了 3.14，打印出来是 3」这种困惑。

## 类型不是标签，是尺寸和解释方式

C 的基本类型有明确的字节数（在 64 位 Linux/macOS 上）：

| 类型 | 字节 | 能表示的范围 | 典型用途 |
|---|---|---|---|
| `char` | 1 | -128 ~ 127 | 单个字符、小整数 |
| `int` | 4 | 约 ±21 亿 | 计数、下标 |
| `long` | 8 | 很大 | 大整数 |
| `float` | 4 | 约 7 位有效数字 | 不要求精度的浮点 |
| `double` | 8 | 约 15 位有效数字 | **默认选它** |

`float` 和 `double` 的区别不是「精度高一点」，而是有效数字位数差一倍。算 0.1 + 0.2 这种，`float` 的误差会明显到肉眼可见。

**日常规则：小数一律用 `double`**，除非你在写图形学或嵌入式且明确知道为什么用 `float`。

## 声明、初始化、赋值是三件事

```c
int a;          // 声明：分配了空间，内容是垃圾值
int b = 10;     // 初始化：分配并且立刻写入 10
a = 5;          // 赋值：把 5 写进已分配的空间
```

初学者最容易踩的是第一种。`int a;` 之后直接 `printf("%d", a)` 会输出一个莫名其妙的数，因为那块内存里是上一个程序留下的字节。

**养成习惯：声明的同时就初始化**。写 `int a = 0;` 比写 `int a;` 安全得多，代价只是多敲三个字符。

## 命名：让变量名自己解释

C 的命名惯例是下划线风格：

```c
int student_count = 0;      // 好：一眼知道是什么
int n = 0;                  // 差：n 是什么的个数？
double avg_score = 0.0;     // 好
double a = 0.0;             // 差
```

例外是循环下标，`i`、`j`、`k` 是公认的简写，因为它们的作用域通常只有三五行。

变量名不能以数字开头，不能是关键字（`int`、`for`、`return` 这些），大小写敏感（`Count` 和 `count` 是两个变量）。

## 常量用 const，不要用魔法数字

```c
const int MAX_STUDENTS = 60;   // 好
int scores[60];                // 差：60 是什么？
```

后面如果班级人数变了，你只需要改一处。而且编译器会在你不小心修改 `MAX_STUDENTS` 时报错，帮你挡住一类 bug。

## 类型转换：隐式的坑最多

C 会在不同类型混算时自动转换，规则是「往精度高的方向转」：

```c
int a = 5;
double b = 2.0;
double c = a / b;    // a 被转成 double，结果 2.5
```

但**整数除整数还是整数**，这是最高频的错误：

```c
int a = 5, b = 2;
double c = a / b;    // 结果是 2.0，不是 2.5！
```

原因：`a / b` 先按整数除法算出 2，再转成 `double` 变成 2.0。转换发生在除法之后，已经晚了。

正确写法是让除法本身变成浮点运算，两种都行：

```c
double c = (double)a / b;   // 把 a 先转成 double
double c = a / 2.0;         // 让除数是浮点
```

这条规则会一直跟到你写平均数、百分比、评分的时候，务必现在记住。

## 用 sizeof 自己验证

不同平台上 `int` 的字节数可能不同（虽然现在基本都是 4）。想知道确切值，直接问编译器：

```c
printf("int: %zu 字节\n", sizeof(int));
printf("double: %zu 字节\n", sizeof(double));
```

`%zu` 是 `sizeof` 返回类型（`size_t`）的格式符。这个习惯很有用——**不要背平台的差异，让程序自己告诉你**。

## 一个完整的例子

```c
#include <stdio.h>

int main(void) {
    const int TOTAL = 3;
    double score1 = 88.5, score2 = 92.0, score3 = 76.5;

    double sum = score1 + score2 + score3;
    double avg = sum / TOTAL;          // sum 是 double，TOTAL 转成 double，安全

    printf("总分 %.1f，平均 %.2f\n", sum, avg);
    return 0;
}
```

注意 `sum / TOTAL`：`sum` 已经是 `double`，所以整条除法是浮点运算，不需要额外转换。**只要除号两边有一个是浮点，结果就是浮点**。

如果把 `sum` 写成 `int`，这里就会踩整数除法的坑。
