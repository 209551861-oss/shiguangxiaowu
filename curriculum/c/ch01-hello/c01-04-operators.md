运算符看起来是最简单的部分，但它埋着 C 语言里最深的一批坑：整数除法、自增顺序、优先级、浮点比较。

这一节把这些坑一次讲清，后面写循环和指针时才不会莫名出错。

## 算术运算符与整数除法的铁律

`+ - * / %` 里，`%` 是取余，只对整数有效。

**核心规则：两个整数相除，结果还是整数，小数部分直接丢弃（不是四舍五入）。**

```c
7 / 2      // 3，不是 3.5
-7 / 2     // -3（向零截断，不是 -4）
7 % 2      // 1
7.0 / 2    // 3.5
```

截断方向容易搞错：C 是**向零截断**，不是向下取整。`-7 / 2` 得 `-3` 而不是 `-4`。负数取余同理：`-7 % 2` 得 `-1`。

想得到浮点结果，让其中一个操作数是浮点：

```c
double avg = (double)sum / count;
```

## 自增自减：不要在一行里用两次

```c
int i = 5;
int a = i++;    // a = 5, i = 6（先用后加）
int b = ++i;    // i = 7, b = 7（先加后用）
```

单独写 `i++;` 时，`i++` 和 `++i` 完全等价，选哪个都行。

但**绝不要在一个表达式里对同一个变量多次自增**：

```c
int i = 5;
int x = i++ + i++;   // 结果未定义！不同编译器可能给出不同答案
```

这不是「编译器实现差异」，而是 C 标准明确规定为**未定义行为**（undefined behavior）。任何结果都是合法的，包括崩溃。看到这种代码，唯一正确的做法是重写成两行。

## 比较与逻辑：C 没有真正的布尔类型（C99 之前）

关系运算 `> < >= <= == !=` 的结果是 `int`：真为 `1`，假为 `0`。逻辑运算 `&& || !` 同样返回 `0` 或 `1`。

```c
int ok = (5 > 3);      // ok = 1
int bad = (5 < 3);     // bad = 0
```

**把 `==` 写成 `=` 是最经典的 bug**：

```c
if (x = 5) { ... }     // 这是赋值！x 变成 5，条件恒为真
if (x == 5) { ... }    // 这才是比较
```

编译器通常只给警告。一个防错写法是把常量写在左边：

```c
if (5 == x) { ... }    // 少写一个 = 就变成 5 = x，编译器直接报错
```

这个习惯叫「尤达条件」，丑但有效。

## 短路求值：能省事也能埋雷

`&&` 和 `||` 会短路：

- `A && B`：A 为假时，B **不执行**
- `A || B`：A 为真时，B **不执行**

利用这一点可以先判空再访问：

```c
if (p != NULL && p->value > 0) { ... }   // p 为 NULL 时不会解引用，安全
```

顺序不能反。写成 `p->value > 0 && p != NULL`，`p` 为空时就已经崩了。

反面用法（不要这么写）：

```c
if (i < n && arr[i++] > 0) { ... }   // 自增放在条件里，执行次数取决于短路，极难推理
```

## 优先级：记不住就加括号

完整优先级表有十几级，没人靠背。只需记住几条高频的：

| 优先级 | 运算符 |
|---|---|
| 高 | `()` `[]` `->` `.` |
| 中高 | `!` `++` `--` 单目 `-` `(类型)` `*`（解引用）`&`（取地址） |
| 中 | `*` `/` `%` |
| 中低 | `+` `-` |
| 低 | `>` `<` `>=` `<=` |
| 更低 | `==` `!=` |
| 低 | `&&` |
| 最低 | `||` `?:` `=` |

最容易错的三个场景：

```c
if (a & 1 == 0)      // 错：== 优先级高于 &，实际是 a & (1==0)
if ((a & 1) == 0)    // 对

x = a > b ? a : b + 1;   // ?: 优先级很低，实际是 x = (a>b ? a : b+1)
```

**规则：只要一行里有两个以上不同类别的运算符，就加括号。** 括号不花钱，误解花时间。

## 位运算：先知道有，用到再查

`& | ^ ~ << >>` 是位运算，操作的是二进制位。

```c
5 & 3      // 1   （0101 & 0011 = 0001）
5 | 3      // 7   （0101 | 0011 = 0111）
5 ^ 3      // 6   （0101 ^ 0011 = 0110）
1 << 3     // 8   （左移 3 位 = 乘 8）
x >> 1     // 除以 2（对非负数）
```

位运算在初学阶段用得不多，但有两个场景会出现：判断奇偶（`n & 1`）、以及后面学哈希和集合时的标志位。现在知道它们存在、且**优先级低于比较运算**就够了。

## 类型转换的两种写法

```c
double d = 3.9;
int i = (int)d;        // 显式转换，截断成 3
int j = d;             // 隐式转换，同样截断，但意图不明显
```

**优先用显式转换**。它告诉读代码的人「我知道这里会丢失精度」，也方便你之后搜索所有转换点。

注意 `(int)-3.9` 得 `-3`，同样是向零截断，不是 `-4`。

## 浮点数不能用 == 比较

```c
double a = 0.1 + 0.2;
if (a == 0.3) { ... }        // 大概率不成立！
```

因为 0.1、0.2、0.3 在二进制里都是无限循环小数，存储时被截断，累加后误差会累积。正确做法是判断差值足够小：

```c
#include <math.h>
if (fabs(a - 0.3) < 1e-9) { ... }
```

`1e-9` 是 10 的 -9 次方，作为「足够接近」的阈值。这个阈值要根据你的数据量级选，但「用差值比较」这个思路是通用的。

## 小结：四个必须记牢的

1. 整数除整数 = 整数，要浮点就转一个操作数
2. `==` 别写成 `=`，常量放左边
3. 一行里两个以上不同运算符，加括号
4. 浮点数只比差值，不比相等
