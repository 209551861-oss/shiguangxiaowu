程序不能只会输出。要能接收输入，才谈得上「处理数据」。

`printf` 和 `scanf` 这一对是 C 里最常用的 I/O 函数，也是最容易出错的一对——因为它们的格式符必须和变量类型**严格对应**，错了不会报错，只会输出垃圾值或者读到脏数据。

## printf 的本质：格式串 + 参数列表

```c
printf("总分 %.1f，平均 %.2f\n", sum, avg);
```

格式串里的 `%.1f` 和 `%.2f` 是**占位符**，按顺序对应后面的参数。`.` 后面的数字是小数位数。

常用格式符：

| 格式符 | 对应类型 | 说明 |
|---|---|---|
| `%d` | `int` | 十进制整数 |
| `%ld` | `long` | 长整数 |
| `%f` | `double` | 浮点，默认 6 位小数 |
| `%.2f` | `double` | 保留 2 位小数 |
| `%c` | `char` | 单个字符 |
| `%s` | `char *` | 字符串 |
| `%zu` | `size_t` | sizeof 的结果 |

**关键点：`%f` 既用于 `float` 也用于 `double`。** 因为 C 在传参时会把 `float` 自动提升成 `double`，所以 `printf` 里统一写 `%f`。

格式符和参数数量不匹配是最危险的错误：

```c
printf("%d %d\n", 1);        // 少给一个参数，第二个 %d 会打印垃圾值
printf("%d\n", 3.14);        // 类型不匹配，输出是乱码
```

这两种情况**编译器通常不报错**，只是给一个警告（`-Wall` 才能看到）。所以请始终开着警告编译：

```bash
gcc -Wall -Wextra hello.c -o hello
```

## 宽度和对齐

打印表格时很好用：

```c
printf("%-10s %5d\n", "语文", 88);
printf("%-10s %5d\n", "数学", 92);
```

`%-10s` 表示「左对齐，占 10 个字符宽」；`%5d` 表示「右对齐，占 5 个字符宽」。数字右对齐、文字左对齐，表格就会整齐。

## scanf 的本质：把输入按格式拆开

```c
int age;
scanf("%d", &age);
```

注意那个 `&`。**这是初学者最容易漏的符号**。

`scanf` 需要知道「把读到的值写到哪个地址」，所以要传变量的地址（`&age`）而不是值（`age`）。漏了 `&` 的后果：

- 轻则程序崩溃（段错误）
- 重则悄悄写坏别的变量，过一会儿才出问题

唯一的例外是字符串数组，因为数组名本身就是地址：

```c
char name[32];
scanf("%31s", name);      // 不需要 &
```

`%31s` 里的 31 是**宽度限制**，表示最多读 31 个字符，留一个位置给结尾的 `\0`。不写这个限制，输入超过数组长度就会溢出——这是经典的安全漏洞来源。

## 多个输入

```c
int a, b;
scanf("%d %d", &a, &b);
```

用户输入 `3 5` 或 `3   5` 或 `3\n5` 都能正确读到，因为 `%d` 会自动跳过空白字符（空格、制表符、换行）。

但如果你混用 `%d` 和 `%c`，就有坑：

```c
int n;
char ch;
scanf("%d", &n);
scanf("%c", &ch);    // 读到的很可能是换行符，不是你以为的字符
```

原因：读完数字后，输入缓冲区里还留着一个换行符，`%c` 会立刻把它读走。解决办法是在 `%c` 前加一个空格：

```c
scanf(" %c", &ch);   // 前面的空格表示「跳过所有空白再读」
```

这个空格很小但很关键，属于必须记住的细节。

## scanf 的返回值：判断输入是否成功

`scanf` 返回**成功赋值的变量个数**。用它来做输入校验：

```c
int n;
if (scanf("%d", &n) != 1) {
    printf("输入的不是整数\n");
    return 1;
}
```

不加判断的话，用户输入字母，`n` 会保持原来的垃圾值，程序带着错误数据继续跑，最后结果错得莫名其妙。

**养成习惯：只要用了 `scanf`，就检查返回值。**

## 一个完整例子：读两个数求和

```c
#include <stdio.h>

int main(void) {
    double a, b;

    printf("输入两个数（空格分隔）：");
    if (scanf("%lf %lf", &a, &b) != 2) {
        printf("输入格式不对\n");
        return 1;
    }

    printf("%.2f + %.2f = %.2f\n", a, b, a + b);
    return 0;
}
```

注意这里用 `%lf` 读 `double`。**`scanf` 里 `double` 必须用 `%lf`**，用 `%f` 会写坏内存（因为 `%f` 按 4 字节写入，而 `double` 是 8 字节）。这一点和 `printf` 不同——`printf` 里 `%f` 就够了，`scanf` 里必须区分。

记法：**输出可以含糊（都写 %f），输入必须精确（double 写 %lf）**。

## 调试技巧：打印中间值

程序结果不对时，最有效的第一招不是盯着代码看，而是在关键位置插入打印：

```c
printf("DEBUG a=%f b=%f\n", a, b);
```

把中间值打出来，和你的预期对比，问题通常立刻现形。养成这个习惯，比学会调试器更早见效。
