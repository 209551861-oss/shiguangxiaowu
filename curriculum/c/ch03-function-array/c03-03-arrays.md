数组是「一排同类型的格子」。理解它的关键不是语法，而是**下标从 0 开始、长度固定、越界不报错**这三件事。

## 声明与初始化

```c
int a[5];                        // 5 个 int，内容是垃圾值
int b[5] = {1, 2, 3, 4, 5};      // 全部初始化
int c[5] = {1, 2};               // 前两个是 1、2，其余自动补 0
int d[] = {1, 2, 3};             // 长度由初始化列表推出来，d 的长度是 3
```

`c` 的行为值得注意：**部分初始化时，剩下的元素自动补 0**。这不算「未初始化」，是标准规定的。

但 `int a[5];` 完全没初始化，里面是垃圾值。想要全 0：

```c
int a[5] = {0};                  // 常用写法：全部为 0
```

`{0}` 会把第一个元素设为 0，其余自动补 0，效果就是全零。比 `memset` 直观。

## 下标从 0 开始

长度 5 的数组，合法下标是 **0、1、2、3、4**，最大下标是 `长度 - 1`。

```c
int a[5] = {10, 20, 30, 40, 50};
printf("%d\n", a[0]);     // 10  第一个
printf("%d\n", a[4]);     // 50  最后一个
printf("%d\n", a[5]);     // 越界！读到的是别的内存
```

**C 不做越界检查。** 这是设计选择（为了快），代价是越界不报错：

- 读越界：得到一个垃圾值
- 写越界：**悄悄改坏别的变量**，可能在几十行之后才炸

```c
int a[3] = {0};
int b = 123;
a[3] = 999;              // 越界写，可能正好改掉了 b
printf("%d\n", b);       // 可能变成 999
```

这类 bug 极难查，因为它不报错、不崩溃，只是某个无关变量的值变了。

**防御手段**：
1. 循环一律写 `i < n`，不写 `i <= n`
2. 用常量定义长度，别到处写裸数字
3. 函数接收数组时，同时接收长度参数

## 用 sizeof 算长度（只在同一作用域有效）

```c
int a[5];
int n = sizeof(a) / sizeof(a[0]);    // 5
```

原理：`sizeof(a)` 是整个数组的字节数（20），`sizeof(a[0])` 是单个元素的字节数（4），相除就是元素个数。

**但这个技巧只在数组「还在自己作用域里」时有效。** 一旦传进函数，数组会退化成指针（下一节讲），`sizeof` 就变成指针大小了：

```c
void f(int a[]) {
    printf("%zu\n", sizeof(a));   // 8（指针大小），不是数组大小！
}
```

所以函数必须额外接收长度参数。这条规则没有例外。

## 遍历

```c
for (int i = 0; i < n; i++) {
    printf("%d ", a[i]);
}
```

标准写法，只有一种。**不要试图写 `i <= n`**，那是越界。

倒序遍历：

```c
for (int i = n - 1; i >= 0; i--) { ... }
```

注意 `i >= 0`，且 `i` 必须是 `int`（不能是无符号类型，否则 `i--` 到 0 之后会变成极大值，死循环）。这是无符号类型的一个经典陷阱，现在用 `int` 就好。

## 二维数组

```c
int m[3][4];                  // 3 行 4 列
int g[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

访问 `g[行][列]`，下标都从 0 开始。

嵌套遍历：

```c
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", g[i][j]);
    }
    printf("\n");
}
```

**习惯：外层的 `i` 走行，内层的 `j` 走列。** 顺序写反不会报错，但会让内存访问不连续，大数组时慢很多。

## 字符数组就是字符串

```c
char name[8] = "Alice";       // 实际占 6 字节：A l i c e \0
```

**C 的字符串是「以 `\0` 结尾的字符数组」。** 那个 `\0` 是长度的一部分，必须留位置。

```c
char bad[5] = "Alice";        // 错：6 个字符（含 \0）塞进 5 个位置
```

这是编译错误（初始化列表过长）。但在 `scanf` 里不会报错，只会溢出：

```c
char name[5];
scanf("%s", name);            // 输入 "Alice" 就溢出
scanf("%4s", name);           // 安全：最多读 4 个字符
```

**用 `scanf` 读字符串，永远带宽度限制，值是「数组长度 - 1」。**

## 一个完整例子：统计成绩分布

```c
#include <stdio.h>

int main(void) {
    int scores[10];
    int n = 0;

    printf("输入 10 个成绩：\n");
    for (int i = 0; i < 10; i++) {
        if (scanf("%d", &scores[i]) != 1) {
            printf("第 %d 个输入不合法\n", i + 1);
            return 1;
        }
        n++;
    }

    int sum = 0, max = scores[0], min = scores[0];
    for (int i = 0; i < n; i++) {
        sum += scores[i];
        if (scores[i] > max) max = scores[i];
        if (scores[i] < min) min = scores[i];
    }

    printf("平均 %.2f，最高 %d，最低 %d\n",
           (double)sum / n, max, min);
    return 0;
}
```

注意 `max` 和 `min` 的初值取 `scores[0]`，不能取 0——成绩全是负数（虽然不现实）时才是对的，但这个习惯要养成。
