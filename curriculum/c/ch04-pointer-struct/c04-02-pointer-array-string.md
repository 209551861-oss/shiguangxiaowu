数组名和指针的关系，是 C 里最容易被讲糊涂的地方。这一节把它说清楚：数组名在大多数场合会自动变成指向首元素的指针，但不是所有场合。

## 数组名会退化成指针

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;              // 等价于 int *p = &a[0];

printf("%d\n", *p);      // 10
printf("%d\n", *(p+1));  // 20
printf("%d\n", p[2]);    // 30
```

**`a` 在表达式里会自动转成 `&a[0]`。** 所以 `int *p = a;` 合法，不需要 `&`。

四种写法完全等价：

```c
a[i]
*(a + i)
p[i]
*(p + i)
```

编译器生成的是同一份代码。`p[i]` 只是 `*(p + i)` 的语法糖。

## 指针算术：加的是「元素个数」

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
p++;                     // 前进一个 int，地址增加 4 字节（不是 1）
```

**`p + 1` 前进的是 `sizeof(*p)` 个字节**，不是 1 字节。这是指针算术的核心规则。

对 `int *` 是 4 字节，对 `double *` 是 8 字节，对结构体指针是结构体大小。

推论：**指针只能在自己指向的数组范围内移动**。越界后 `p++` 的行为是未定义的。

## 数组名不是指针的两个例外

**例外一：`sizeof`**

```c
int a[5];
printf("%zu\n", sizeof(a));        // 20（整个数组）
printf("%zu\n", sizeof(a[0]));     // 4
```

这里 `a` 没有退化，`sizeof` 拿到的是数组总大小。这就是 `sizeof(a)/sizeof(a[0])` 能算长度的原因。

**例外二：`&` 取地址**

```c
int a[5];
printf("%p\n", (void *)a);        // 首元素地址
printf("%p\n", (void *)&a);       // 整个数组的地址（数值相同，类型不同）
```

数值一样，但类型不同：`a` 是 `int *`，`&a` 是 `int (*)[5]`（指向数组的指针）。加 1 之后差别就出来了——`a+1` 前进 4 字节，`&a+1` 前进 20 字节。

**结论：数组名在「值」上等于首元素地址，但在 `sizeof` 和 `&` 下保持数组身份。**

## 字符串：以 \0 结尾的字符数组

```c
char s[] = "hello";       // 6 字节：h e l l o \0
char *p = "hello";        // p 指向只读区的一个字符串常量
```

两者看起来一样，但**关键区别**：

```c
s[0] = 'H';       // 可以，s 是数组，可写
p[0] = 'H';       // 错！字符串常量在只读区，写会崩溃
```

**`char *p = "hello"` 中 p 指向的是只读内存。** 这是新手常踩的坑，因为编译能过，运行时才崩。

想用指针指向可写字符串，必须指向数组：

```c
char buf[] = "hello";
char *p = buf;         // p 现在指向可写的数组
p[0] = 'H';            // 可以
```

## 遍历字符串：两种写法

```c
// 用下标
for (int i = 0; s[i] != '\0'; i++) putchar(s[i]);

// 用指针
for (char *p = s; *p != '\0'; p++) putchar(*p);
```

指针版本少了一个下标变量，但两种都可读。**用 `\0` 判断结束是固定套路**，不能用长度（因为字符串本身不记长度）。

## 为什么 `scanf("%s")` 不需要 &

```c
char name[32];
scanf("%s", name);        // name 已经是地址，不需要 &
```

因为数组名在传参时自动退化成指针。写 `&name` 类型会变成「指向数组的指针」，虽然地址值相同但类型不匹配，某些情况下会出问题。

**规律：`scanf` 里，普通变量要 `&`，字符数组不要。**

```c
int n;
char name[32];
scanf("%d %s", &n, name);      // 对比一下，一个有一个没有
```

## 指针遍历数组的实用场景

```c
int sum(int *begin, int *end) {    // [begin, end) 半开区间
    int s = 0;
    for (int *p = begin; p != end; p++) s += *p;
    return s;
}

int a[5] = {1, 2, 3, 4, 5};
printf("%d\n", sum(a, a + 5));     // 15
```

「用两个指针表示区间」是 C 里非常常见的接口设计，标准库的 `std::vector`、`qsort` 都这么用。**半开区间 `[begin, end)` 的好处是空区间也能统一处理**（`begin == end`），不用特判。

## 一个完整例子：自己实现字符串长度

```c
#include <stdio.h>

size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p != '\0') p++;
    return (size_t)(p - s);        // 指针相减 = 元素个数
}

int main(void) {
    char buf[] = "hello, c";
    printf("%zu\n", my_strlen(buf));   // 8
    return 0;
}
```

**指针相减得到的是「相隔多少个元素」**，不是字节数。这是指针算术的对称性质：加 N 前进 N 个元素，减出来的也是 N。

`const char *` 表示「我不会修改它指向的内容」。这是一个承诺，也是给读代码的人的信息。**凡是只读的参数，都应该加 `const`。**

## 常见错误

| 写法 | 问题 |
|---|---|
| `char *p = "abc"; p[0]='x';` | 往只读区写，崩溃 |
| `int *p = a; p += 10;` | 越界，未定义行为 |
| `sizeof(a)` 在函数内 | 拿到的是指针大小 |
| `scanf("%s", &name)` | 类型不匹配（虽然多数编译器能过） |
| 忘了 `\0` 判断 | 遍历越界 |
