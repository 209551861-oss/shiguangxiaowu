指针是 C 的门槛，也是它的核心。理解了指针，才能理解数组、字符串、链表、动态内存——它们本质上都是指针的不同用法。

这一节只讲清三件事：什么是地址、怎么取怎么用、为什么它在函数间传递时这么关键。

## 变量有地址

内存可以想象成一排编了号的小格子，每个格子 1 字节。变量的地址就是它占用的第一个格子的编号。

```c
int a = 42;
printf("值：%d\n", a);
printf("地址：%p\n", (void *)&a);     // 类似 0000008a5f3ff9ac
```

`&` 是**取地址运算符**。`%p` 是专门打印指针的格式符。

每次运行地址可能不同（操作系统会随机化栈基址），这很正常。

## 指针就是一个存地址的变量

```c
int a = 42;
int *p = &a;        // p 存的是 a 的地址，类型是「指向 int 的指针」
```

读法（很重要）：**从右往左读**。`int *p` 读作「p 是一个指针，指向 int」。

两种写法的位置：

```c
int *p;      // 常见：星号贴着变量
int* p;      // 也可以，语义完全一样
```

多变量声明时要注意：

```c
int *a, b;   // a 是指针，b 是普通 int！星号只作用于紧邻的那个变量
int *a, *b;  // 两个都是指针
```

**建议一行只声明一个指针**，避免这种歧义。

## 两个方向的操作

**解引用（`*p`）：通过地址访问内容**

```c
int a = 42;
int *p = &a;
printf("%d\n", *p);    // 42
*p = 100;              // 通过地址改 a
printf("%d\n", a);     // 100
```

**取地址（`&p`）：得到指针自己的地址**（很少直接用）

```c
int **pp = &p;         // 指向指针的指针
```

一开始只需要掌握 `&a` 拿地址、`*p` 拿内容这两个动作。`**` 层级别急着学。

## 指针的两种「空」

```c
int *p = NULL;         // 空指针：明确表示「不指向任何东西」
int *q;                // 野指针：值不确定，可能指向任何地方
```

**用 `NULL` 表示「没有」，并且每次解引用前检查：**

```c
if (p != NULL) {
    printf("%d\n", *p);
}
```

**野指针是崩溃的主要来源。** `int *q;` 之后 `*q = 5;` 是在往一个随机地址写数据，可能：

- 立即段错误（运气好）
- 悄悄改坏别的变量，几十行后才发现（运气差）

**规则：指针声明时就初始化为 `NULL`。**

```c
int *p = NULL;         // 好习惯
```

## 为什么函数改不了外面？现在有答案了

回到第 3 章那个问题：

```c
void try_change(int x) { x = 999; }      // 改的是副本
```

有了指针，就能真正改到：

```c
void really_change(int *x) { *x = 999; }

int main(void) {
    int a = 5;
    really_change(&a);       // 传地址
    printf("%d\n", a);       // 999
}
```

**这是指针最实用的用途：让函数能修改调用者的变量。**

写这种函数的固定套路：

1. 参数声明成 `类型 *`
2. 函数体内用 `*参数` 读写
3. 调用时传 `&变量`

## 函数返回多个值

```c
/* 同时算出商和余数；成功返回 1，除零返回 0 */
int divide(int a, int b, int *q, int *r) {
    if (b == 0) return 0;
    *q = a / b;
    *r = a % b;
    return 1;
}

int main(void) {
    int q, r;
    if (divide(17, 5, &q, &r)) {
        printf("商 %d 余 %d\n", q, r);     // 商 3 余 2
    }
}
```

调用者提供变量地址，函数往里填。这是 C 里返回多个结果的标准做法，你会在大量的库函数里见到（比如 `sscanf`、`time`、`stat`）。

## 交换两个数：指针的经典练习

```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);
    printf("%d %d\n", x, y);      // 2 1
}
```

**不传指针的版本是无效的**：

```c
void bad_swap(int a, int b) {
    int t = a; a = b; b = t;      // 只改了副本，调用者没变
}
```

这个对比是理解值传递最好的例子。自己写一遍，用两种方式各试一次，看输出差异。

## 指针的类型很重要

```c
int a = 42;
double *p = &a;        // 编译警告：类型不匹配
```

指针的类型决定了**解引用时读几个字节、怎么解释**。`int *` 读 4 字节按整数解释，`double *` 读 8 字节按浮点解释。类型错了，读出来的就是乱的。

强制转换能编译通过，但结果通常没意义：

```c
double *p = (double *)&a;    // 能编译，但 *p 是垃圾
```

## 常见崩溃及原因

| 现象 | 原因 |
|---|---|
| 段错误（Segmentation fault） | 解引用了 `NULL` 或野指针 |
| 值莫名其妙变了 | 越界写了别的变量 |
| 打印出来是乱码 | 类型不匹配（用 `%d` 打印 `double*` 之类） |
| 程序随机崩在不同位置 | 之前某处越界写坏了内存 |

**排查第一步永远是：在可疑位置打印指针的值和它指向的内容。**

```c
printf("DEBUG p=%p *p=%d\n", (void *)p, p ? *p : -1);
```
